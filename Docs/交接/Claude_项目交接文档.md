## 1. 需求与最终交付目标

开发可在 macOS 13+（Apple Silicon/Intel）使用的原生 SwiftUI 桌面应用 **Stockbee Market Monitor / 美股动量交易环境监控**。用户希望自动提取 https://stockbee.blogspot.com/p/mm.html 发布的最新美股市场广度指标，结合指数/板块行情自动计算一套**自定义100分市场环境评分**，在同一个窗口内形成 VCP（Minervini）及 HTF（Qullamaggie）交易环境建议。用户特别要求“真实数据而不是展示用假数值”，交付之前必须检查。

### 已确定的 UI 版式

- 顶栏：应用名称、最后完整美股交易日（America/New_York）、最近检查时间、手动刷新、数据来源设置、官方/第三方和数据时效标签。
- **左侧**：当日最新的4% Up/Down、3D/5D/10D Ratio、Quarter Ratio、Quarter Up/Down、T2108、SPY/QQQ趋势、XLK/SMH/XLY板块领导力；状态和参考阈值；近10个交易日的4% Up/Down柱状图。
- **右上**：7个模块的100分评分表（权重、实际得分、数据缺失状态）及 A/B/C/D 等级区间。
- **右下**：总分环、当前环境等级、Minervini VCP建议及Qullamaggie HTF建议；清晰显示阻止计算分数的来源/日期/异常信息。
- 视觉：蓝白色macOS原生控制台风格；参考 `Design/02_原型图_A.png` 与 `Design/03_原型图_B.png`，但**不要复制两张原型的模拟数据到产品**。用户原始评分截图为 `Design/01_用户提供的100分评分参考截图.png`。

## 3. 已实现功能（指源码内已有的逻辑，不等于真实数据已经可用）

1. 通过访问Stockbee官方页面自动寻找公开Google Sheets链接，再尝试CSV/HTML解析；支持用户提供Sheet链接（这种情况标记“官方关联未核验”）。
2. 可选Stage2Stocks第三方替代源，**必须显著标注“非官方、股票池及指标定义可能不同”**。
3. 支持4% Up/Down、Quarter Up/Down、T2108及3D/5D/10D比率的计算，避免分母为0、历史日数不足时强制出值；有公开5D/10D比率时做一致性检查。
4. 通过Yahoo Finance日线、失败时尝试Stooq获取SPY/QQQ、XLK、SMH、XLY；不同来源不得混用于板块相对强度；必须匹配Stockbee最新交易日。
5. 7个评分模块，全部有效才公布总分和等级；不完整时展示已得/可用权重并“待评估”，**不能将缺失数据视为0分**。
6. 原生SwiftUI左右栏、Charts近10日柱图、等级卡、两种策略建议；启动时及每15分钟联网检查，用户可手动刷新。
7. 接口失败清除过时评分，展示异常及未认证数据源提示。

## 4. 数据定义、来源和时效性要求

- **Stockbee官网**：https://stockbee.blogspot.com/p/mm.html 。应从该页面**实际存在**的嵌入资源获取；不要在未确认时硬编码Google Sheet ID；不绕过认证、付费或访问限制。
- **4% Up / 4% Down**：Stockbee市场监控口径的单日上涨/下跌4%股票数量，若源端附加成交量/股票池过滤条件应使用源端定义；第三方算法不可冒充官方。
- **3D / 5D / 10D Ratio**：最近N个**交易日**的4% Up合计 / 4% Down合计，而非N个自然日或每日比值的算术平均；要以官方网站当时的指标定义做最终核验。Quarter Ratio：约一个季度上涨≥25%的股票数 / 下跌≥25%的股票数。
- **T2108**：若官方表格存在合法的0–100值，则按百分数使用；若没有，不可编造数值，需确定授权、可核实的独立来源。界面原有“Russell 3000广度”只做相关广度的代理标签，**T2108不等于直接测量Russell 3000所有成分股的广度**。
- **指数/板块补充数据**：SPY、QQQ、XLK、SMH、XLY；使用有来源标记的行情，注明收盘时间/最新有效交易日。Yahoo / Stooq公开端点可能限流或结构变化，不应承诺有SLA或秒级实时性。
- **时间纪律**：以America/New_York解释美股交易日（含夏令时），收盘后源尚未更新时继续显示“最新已发布交易日”；不得将前一交易日的数据说成今日数据。自动检查间隔15分钟只是轮询频率，Stockbee数据通常是收盘后的广度汇总，**不是盘中逐笔实时**。
- **评分日期纪律**：最新广度数据与全部ETF行情的评价日期必须一致，缺失/混合来源/过时应阻止发布完整等级。还应加固节假日、周末、源端时区和历史报价的检测。

## 5. 自定义100分算法（当前实现，未来变更必须标注版本）

| 评分项 | 最高分 | 当前代码中的阶梯计算 |
|---|---:|---|
| Stockbee Quarter Ratio | 20 | ≥1.5:20；≥1:15；≥0.7:8；其余0 |
| Stockbee 10D Ratio | 15 | ≥2:15；≥1.3:11；≥1:7；其余0 |
| Stockbee 5D Ratio | 5 | ≥2:5；≥1.3:4；≥1:3；其余0 |
| Stockbee 3D Ratio | 5 | ≥1.5:5；≥1:3；其余0 |
| SPY/QQQ指数趋势 | 25 | 对各指数：收盘高于SMA20加4，高于SMA50加5，SMA20高于5个交易日前加3；两个指数各12分且全部满足时额外加1 |
| T2108 广度代理 | 20 | ≥70%:20；≥60%:17；≥50%:12；≥40%:7；其余0 |
| XLK/SMH/XLY相对SPY领导力 | 10 | 最近20个共同交易日相对SPY价格比率上涨：XLK+3、SMH+4、XLY+3 |
| **合计** | **100** | **全部七项可用、日期匹配才有总分/等级** |

等级与策略（仅用于市场环境过滤，不是个股买卖建议）：

| 等级 | 总分 | VCP · Minervini | HTF · Qullamaggie |
|---|---:|---|---|
| A | 80–100 | 按计划参与，仍要确认Pivot、放量、止损 | 可参与，等待有效HTF突破 |
| B | 65–79 | 精选强势股，小仓位 | 仅极强领涨股，控制风险 |
| C | 45–64 | 原则上观察，不追突破 | 暂停新仓 |
| D | 0–44 | 暂停新仓 | 暂停新仓 |
| 待评估 | 任一必要数据缺失 | 不根据完整评分开仓 | 不根据完整评分开仓 |

**重要**：权重来自用户先前讨论的实验性策略过滤器，不是Stockbee官方评分体系；阶梯打分阈值是现有版本自己的实现细则，尚**没有历史有效性回测**。不要声称A级就有获利保证。用户此前以1R=$500作为个人交易风险基准，但应用不应读取真实账户或自动下单，也不要未经要求写入实际仓位管理。
